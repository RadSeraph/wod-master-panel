# wod-master-panel

## Changelog

### v2.0.4 — Корень ошибок скрытности: убран флаг `blind`, починена аудитория ресурсов
- **П.1/П.4 Скрытые броски (дисциплины и стрельба)**: настоящая причина «работы в обратку» и «не работает вообще» — флаг `blind: true` в данных сообщения вместе с `whisper`. В Foundry `blind` относится к кубикам (notación ролла), а не к тексту, и при заранее вычисленном ролле вызывал исключение отрисовки «Roll is not visible to current user» — сообщение не показывалось НИ У КОГО. Теперь скрытность реализована только полем `whisper = [все мастера + сам кидающий]` (функция `blindAudience()`, список мастеров строится из `game.users`, без ненадёжного `getWhisperRecipients("GM")`). Флаг `blind` удалён из всех мест (атака, урон, нулевой пул, промах защиты, дисциплины); кубам Dice3D больше не передаётся `hide=true`. Обычные броски — публичны, скрытные видят мастера и кидающий, остальные игроки — нет.
- **П.3 Потери/приобретения от мастера**: исправлена опечатка типа проверки — было `Array.isArray(actor.getOwnerUserIDs)` (массив — это функция? всегда `false`), из-за чего ID владельца актёра никогда не попадали в аудиторию и игрок не видел траты своих ресурсов мастером. Теперь `typeof === "function"` + запасные варианты через `actor.permissions` / `actor.ownership`. Сообщения вкладок «Здоровье»/«Ресурсы» и списания Крови/Воли адресуются: владелец актёра + все мастера + кликающий.
- П.2 (объединённое сообщение промаха) — без изменений, работает.

### v2.0.3 — Аудитория чата и промах одним сообщением (по замечаниям стола)
- **П.1/П.4 Скрытые броски**: исправлена логика видимости. В Foundry сообщение с `whisper` видят ТОЛЬКО перечисленные пользователи, а `getWhisperRecipients("GM")` возвращает только OTHERх ГМов. Из-за этого скрытный бросок мастера при единственном ГМ уходил в пустой список и не видел никто («перестал работать»), а игроку его собственный результат был недоступен. Теперь аудитория скрытного броска = все мастера + сам кидающий (общие функции `blindAudience()` / `addAuthorToWhisper()`). Остальные игроки — как и раньше, не видят ничего. Относится к дисциплинам, стрельбе (атака/урон/проверка защиты) и кубам Dice3D.
- **П.1 Обычные броски на дисциплинах игроков** работали корректно (видны всем) — проверено, изменений не потребовалось; «наоборот» выглядели именно скрытные броски из-за бага выше.
- **П.2 Промах в стрельбе**: второе сообщение «Имя промахивается.» убрано — фраза о промахе уже показывается в основной карточке атаки строкой «ПРОМАХ» / «ПРОВАЛ (Ботч)» вместо числа успехов (при нулевых успехах больше двух сообщений нет).
- **П.3 Потери/приобретения от мастера**: вы правы — раньше сообщения вкладок «Здоровье» и «Ресурсы» шептались только мастерам (`getWhisperRecipients("GM")` + сам кликающий, если это игрок). Теперь аудитория = владелец затронутого актёра + все мастера + сам кликающий (функции `resourceAudience()` / `addAuthorToWhisper()`); то же применено к списаниям Крови/Воли в дисциплинах и стрельбе. Чужие остатки по-прежнему скрыты от других игроков.

### 1.4.3 — Откат правил по требованию стола
- **Воля**: возвращено прежнее поведение — потраченная Воля ВСЕГДА даёт +1 успех, независимо от результата кубов (правило «только при наличии успеха» отменено). Касается бросков дисциплин и атаки стрельбы.
- **Урон стрельбы**: возвращён искусственный минимум — пул урона не может быть меньше 1 куба; вычитание единиц из урона отменено (единицы показываются в карточке справочно, но на итог не влияют).
- **Скрытные броски**: сообщение со результатом скрытного броска видит ТОЛЬКО GM (автор его не видит — в этом смысл скрытности). Кубы Dice3D при этом летят всегда: кидающий видит свои кубы, остальные — нет.

### 1.4.2 — Исправления по отзывам
- **Ресурсы**: в чат теперь выводится дельта (+/-N) и остаток (Кровь/Воля на вкладке ресурсов, а также списания Крови/Воли при использовании дисциплин).
- **Дисциплины**: восстановлены кубы Dice3D при скрытном броске (кубы видят автор + GM); результат скрытного сообщения тоже шёпчется автору; состав пула в чате теперь в формате `Атрибут (X) + Навык (Y) ... = N`.
- **Стрельба (атака)**: исправлено правило Воли — +1 успех даётся только если на кубах есть хотя бы один успех (раньше добавлялся всегда, даже при нуле); при нуле успехов бросок провален, сообщение «Воля не помогает».
- **Стрельба (урон)**: учтены единицы — каждая 1 на кубе отменяет один успех урона; убрано искусственное «минимум 1 урон» (при полном провале — «УРОН НЕ ПРОШЕЛ», урон 0).
- **Скрытые броски стрельбы**: кубы Dice3D летят всегда (скрытно — только автору и GM); карточки сообщений шёпчутся и автору тоже.
- **Формат чата**: в карточках атаки/урона добавлена строка суммы успехов в формате `Всего (кубики − единицы + Воля = N)` по аналогии с составом пула.

### 1.4.0 — Слияние с `wod-firearms-test` (стрельба)
- Стрельба стала четвёртой вкладкой **«Огонь»** основного пульта: отдельная плавающая красная кнопка и второй модуль больше не нужны.
- **Логика ран приведена к единой (материнской)**: штрафы от ран, блокировка действий «При смерти» и пути к данным (`CONFIG.willPath` для списания Воли) теперь берутся из этого модуля — дублирующий код из `wod-firearms-test` удалён. При слиянии сохранено поведение обеих панелей; намеренное отличие дочернего модуля (автозакрытие панели при выстреле) убрано — пульт остаётся открытым.
- Ромбовидное меню расширено до четырёх разноцветных кнопок: **Здоровье** (зелёная, верх), **Ресурсы** (синяя, лево), **Дисциплины** (фиолетовая, право), **Огонь** (красная, низ). Позиция меню по-прежнему перетаскивается и запоминается.
- Добавлены шаблоны карточек чата `templates/chat-fire-attack.html`, `templates/chat-fire-damage.html` и стили стрельбы в `styles/main.css`.
