# wod-master-panel

## Changelog

### v2.0.8 — Исправления по комментариям стола (кровь-галка, ручной штраф, кубы скрытных бросков)
- **Пункт 1:** Галка «Тратить Кровь на лечение» снова работает как переключатель: при снятой галке лечение проходит бесплатно (кровь не списывается и действие НЕ блокируется); при включённой — дробящий и летальный лечатся за 1 Кровь/ячейку, аггравированный за 5.
- **Пункт 3:** Поле «Бонус/Штраф кубов» в дисциплинах больше не сбрасывается в 0 при перерисовке блока (например, при установке галки «Игнорировать штрафы от ран») — введённая ручная поправка сохраняется. Сама галка влияет только на автоматические штрафы ран.
- **Пункт 6:** Исправлен показ кубов Dice3D при скрытных бросках неписей (дисциплины, выстрел, урон): раньше Foundry подавлял полёт кубов для blind-бросков ГМ. Теперь кубы летят и видны мастеру и владельцу актёра; для скрытного броска игрока сохранён прежний режим.
- Пункты 2, 4, 5 подтверждены как исправленные в v2.0.7 (аудитория чата, открытый/скрытный выстрел, трата Воли).

### v2.0.7 — Исправления по комментариям стола (кровь, чат, скрытные броски)
1. **Лечение Кровью**: дробящий и летальный урон — по 1 Крови за ячейку, аггравированный — 5 Кровей (раньше дробящий лечился бесплатно). Лечение без включённой галки «Тратить Кровь на лечение» по-прежнему блокируется, в уведомлении теперь указаны расценки.
2. **Аудитория сообщений**: все сообщения модуля идут через единый конструктор аудитории; автор сообщения гарантированно получает его даже при нескольких ГМ/режиме ассистента (скрытые броски мастерских персонажей больше не «уходят всем»).
3. **Галка «Игнорировать штрафы ран»** влияет только на автоматический штраф от состояния ран; ручная поправка «Бонус/Штраф кубов» применяется всегда.
4. **Открытый бросок** дисциплин и выстрел (в т.ч. с тратой Воли) — публичные; шёпот ставится только при включённой галке «Скрытный».
5. **Трата Воли на выстрел** больше не делает бросок скрытным.
6. **Кубы Dice3D при скрытном броске** видны кидающему (автору) и мастерам, скрыты для остальных.

### v2.0.6 — Исправления по ТЗ стола (кровь, чат, специализация, Воля)
- **Пункт 1 (стоимость лечения Кровью)**: дробящий (bashing) лечится бесплатно, летальный (lethal) — 1 Кровь за ячейку, аггравированный (aggravated) — 5 Кровей за ячейку (`bloodCost = hl * 1 + ha * 5`). Дополнительно: при снятой галке «Тратить Кровь на лечение» лечение с ценой теперь блокируется с предупреждением — раньше оно проходило молча бесплатно, из-за чего казалось, что правила «сбились».
- **Пункт 2 (аудитория сообщений в чате)**: траты и восстановление Крови/Воли/здоровья видят игрок-владелец и мастер; когда мастер тратит ресурсы неписей со своей панели — сообщение видит только мастер. Убран фолбэк `CONST.USER_PERMISSIONS` (в Foundry V13+ константа удалена и роняла пульт с ошибкой `can't access property "OWNER", CONST.ENTITY_PERMISSIONS is undefined`); владельцы определяются через `actor.owners`, при его отсутствии — через `actor.testUserPermission(u, "OWNER")`.
- **Пункт 3 (специализация)**: галка «Специализация» больше не блокирует использование дисциплин. Состояние чекбокса сохраняется между перерисовками блока (раньше сбрасывался при смене сложности и т.п.), а если у навыка нет заполненной speciality — галка автоматически снимается в момент броска, и бросок проходит как обычный вместо ошибки.
- **Пункт 4 (трата Воли)**: списание Воли при использовании дисциплин и при выстреле снова отображается в чате строкой в родительском формате «Потрачено N Воли (осталось M)», видимой игроку-владельцу и мастеру. Исправлен баг `Array.isArray(actor.getOwnerUserIDs)` (это метод, проверка всегда давала false) — из-за него игрок не видел ни карточку с тратой Воли, ни результат броска. Версия модуля в `module.json` приведена в соответствие: 2.0.6, URL загрузки — asset v2.0.6.

### 1.4.3 — Откат правил по требованию стола
- **Воля**: возвращено прежнее поведение — потраченная Воля ВСЕГДА даёт +1 успех, независимо от результата кубов (правило «только при наличии успеха» отменено). Касается бросков дисциплин и атаки стрельбы.
- **Урон стрельбы**: возвращён искусственный минимум — пул урона не может быть меньше 1 куба; вычитание единиц из урона отменено (единицы показываются в карточке справочно, но на итог не влияют).
- **Скрытные броски**: сообщение со результатом скрытного броска видит ТОЛЬКО GM (автор его не видит — в этом смысл скрытности). Кубы Dice3D при этом летят всегда: кидающий видит свои кубы, остальные — нет.

### 1.4.2 — Исправления по отзывам
- **Ресурсы**: в чат теперь выводится дельта (+/-N) и остаток (Кровь/Воля на вкладке ресурсов, а также списания Крови/Воли при использовании дисциплин).
- **Дисциплины**: восстановлены кубы Dice3D при скрытном броске (кубы видят автор + GM); результат скрытного сообщения тоже шёпчется автору; состав пула в чате теперь в формате `Атрибут (X) + Навык (Y) ... = N`.
- **Стрельба (атака)**: исправлено правило Воли — +1 успех даётся только если на кубах есть хотя бы один успех (раньше добавлялся всегда, даже при нуле); при нуле успехов бросок провален, сообщение «Воля не помогает».
- **Стрельба (урон)**: учтены единицы — каждая 1 на кубе отменяет один успех урона; убрано искусственное «минимум 1 урон» (при полном провале — «УРОН НЕ ПРОШЕЛ», урон 0).
- **Скрытые броски стрельбы**: кубы Dice3D летят всегда (скрытно — только автору и GM); карточки сообщений шёпчутся и автору тоже.
- **Формат чата**: в карточках атаки/урона добавлена строка суммы успехов в формате `Всего (кубики − единицы + Воля = N)` по аналогии с составом пула.
